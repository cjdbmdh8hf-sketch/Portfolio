# Niko Mandic — Portfolio

Persönliches Portfolio von Niko Mandic (Wirtschaftspsychologie, Branding & Social Media).
Löst die bisherige Readymag-Seite (nikomandic.de) ab.

## Struktur

- `index.html` — Startseite (aktuell: Design-Vorschlag / v1)

## Entwicklung

Statische Seite, kein Build-Schritt nötig. Lokal ansehen:

```bash
open index.html
```

oder mit einem kleinen lokalen Server:

```bash
npx serve .
```

## Deployment

Hosting über [Netlify](https://netlify.com), verbunden mit diesem Repo. Jeder Push auf `main` deployed automatisch.
